## Module 1 : Functional Programming with Purr

purrr provides a complete, consistent set of tools for working with
functions and vectors. It replaces the conceptually fragmented \*apply
family with a unified, type-safe interface. For researchers running the
same analysis across many groups, files, or models, purrr is
trans-formative.

list. Variants enforce output types, preventing silent coercions.

### 1. Basic `map()` — Single Argument

`map(x, f)` iterates over `x`, passing each element as the **first
argument** to `f`. It always returns a **list**. x is the iterable and f
is the function.

``` r
# Say we want to map a function that squares each element in a vector
elements = c(1:5)
square <- map(elements, function(x) x^2)
# let's unlist it to get flattened output
unlist(square)
```

    ## [1]  1  4  9 16 25

**We could have written this same function in a different way:**

Tilde is a shorthand for function(.x) and after tilde is the expression
on each item

``` r
 squared <- map(elements, ~ .x^2)
 unlist(squared)
```

    ## [1]  1  4  9 16 25

#### **Map_dbl()**

map_dbl() returns a numeric(double vector): Note that the output is a
vector and doesn’t need unlisting like the map that returns a list.

``` r
# let's use the map to find the squares of elements: 
map_dbl(elements, ~ .x^2)
```

    ## [1]  1  4  9 16 25

``` r
# this is the modern way of writing anonymous function passed to map family
map_dbl(elements, \(x) x^2)
```

    ## [1]  1  4  9 16 25

``` r
# let's create a list of students information 
students <- list(
  score_1 = c(56,70,85,90),
  score_2 = c(75,90,96,45)
)
```

``` r
# you can pass the function in straight if it is not a custom function
map_dbl(students,mean)
```

    ## score_1 score_2 
    ##   75.25   76.50

#### map_int()

maps elements of an iterable to a function and returns integers: Let’s
do the same with the students data

``` r
# let's use int for max: max returns an integer 
map_int(
  students, max
)
```

    ## score_1 score_2 
    ##      90      96

#### map_chr()

``` r
# maps an iterable to a function and returns a character 
map_chr(c('Jane','Matt','Slicker'), ~ paste(":Sly1",.x)) 
```

    ## [1] ":Sly1 Jane"    ":Sly1 Matt"    ":Sly1 Slicker"

### 2.0 map2() and pmap() — Multiple Inputs

**`map2(x,y, f)`** iterates over **two** vectors x and y simultaneously,
passing paired elements to f (function)

``` r
# using lambda shorthand(tilde)
prices  <- list(10, 20, 30)
qty     <- list(3, 5, 2)
map2_dbl(prices,qty, ~ .x * .y)
```

    ## [1]  30 100  60

``` r
# could be written or run this way
map2_dbl(prices,qty, \(x,y) x*y)
```

    ## [1]  30 100  60

``` r
# we could equally write and name our function and later pass it to map2
# this looks cleaner
multiplier <-  function(a,b) a*b
map2_dbl(prices,qty, multiplier)
```

    ## [1]  30 100  60

``` r
first_names <- c("Alice", "Bob", "Carol")
last_names  <- c("Smith", "Jones", "White")
# let's combine the names 
map2_chr(first_names,last_names, paste)
```

    ## [1] "Alice Smith" "Bob Jones"   "Carol White"

### `pmap()` — Multiple Arguments (p = parallel)

`pmap(x,y,z,.. f)` takes a **list of vectors** and passes corresponding
elements as arguments. Perfect for 3+ arguments.

``` r
# Let's take this data and generate some radom normal distribution from it
params_named <- list(
  mean = c(0,  5, 10),
  sd   = c(1,  2,  3),
  n    = c(10, 10, 10)
)
# let's map this data to an rnorm function: it takes the argument, n, mean and sd
pmap(params_named,rnorm)
```
